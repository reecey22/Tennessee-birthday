# Niah's Day Out in Tennessee

View site here: reecey22.github.io/Tennessee-birthday

A birthday day-trip page for Chattanooga: the schedule, a date vote, activity opt-ins, outfit ideas, a purse checklist, and a live RSVP guest list.

| File | What it is |
|---|---|
| `index.html` | The trip page. Open it in a browser or host it on GitHub Pages or Netlify. |
| `Code.gs` | The Google Apps Script that saves RSVPs to a Google Sheet. |
| `SETUP.md` | Step-by-step setup: Google Sheet, script deployment, and hosting. |

RSVPs stay off until you paste your Apps Script web app URL into `index.html` (search for `PASTE_YOUR_WEB_APP_URL_HERE`). See `SETUP.md`.

> Anyone with the page link can read the guest list (names, choices, notes). Don't put private details in RSVP notes.
